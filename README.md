# WorkPulse AI

AI-powered workforce productivity and project management platform built using the MERN stack.

## Features

- Role-Based Authentication
- Project Management
- Task Assignment
- Worklogs
- Notifications
- Analytics Dashboard
- AI Reports
- PDF Export
- AI Assistant

## Tech Stack

- React.js
- Redux Toolkit
- Tailwind CSS
- Node.js
- Express.js
- MongoDB
- OpenRouter AI
